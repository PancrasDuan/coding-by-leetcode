1. 每次只决定一个位置

题目要求把互不相同的数字排出所有顺序。对于 [1,2,3]，第一个位置有 3 种选择，第二个位置有 2 种，最后只有 1 种，一共 6 个结果。

[]
├─ [1] ─ [1,2] ─ [1,2,3]
│      └ [1,3] ─ [1,3,2]
├─ [2] ─ [2,1] ─ [2,1,3]
│      └ [2,3] ─ [2,3,1]
└─ [3] ─ [3,1] ─ [3,1,2]
       └ [3,2] ─ [3,2,1]

递归调用的含义是：当前前缀已经选好了，请把剩下的位置继续填完。例如前缀是 [1] 时，接下来只需要处理 2 和 3。

2. 三份状态就够了

变量含义初始状态
path这条分支已经选出的数字[]
used[i]nums[i] 是否在当前路径中全部为 false
res保存完整排列[]

used 按数组下标记录使用情况，不是把数字当作下标；数字可能是负数。它只表示当前路径中的占用，完成一次排列并不会永久用掉数字。

动作pathused
选择 1[1][true,false,false]
选择 2[1,2][true,true,false]
选择 3，保存排列[1,2,3][true,true,true]
返回到 [1,2]，撤销 3[1,2][true,true,false]
这一层没有其他选择，返回到 [1]，撤销 2[1][true,false,false]
接着选择 3[1,3][true,false,true]
继续选择 2，保存排列[1,3,2][true,true,true]

每次递归结束，必须撤销本次选择，让 path 和 used 回到选择之前的状态，下一条分支才有相同的起点。

这就是 Stanford 回溯课程中的“选择 → 探索 → 撤销”。返回会结束当前函数调用，但不会自动撤销共享列表的修改。

3. 转成实现步骤

准备 res、空 path、全为 false 的 used
从空路径开始递归

每次递归：
  如果 path 已有 n 个数字：保存它的副本，结束当前调用
  否则，遍历所有下标 i：
    如果 used[i] 为 true：跳过
    选择：加入 nums[i]，标记已使用
    探索：调用 explore，递归填写下一个位置
    撤销：移除刚加入的数字，取消使用标记

每层都从下标 0 开始遍历，再用 used 排除当前路径里的数字。如果限制后面只能选更大的下标，会漏掉 [2,1,3] 等顺序。

保存结果要用 res.add(new ArrayList<>(path))。直接加入 path 会让结果指向同一个可变列表，后续撤销也会改变它。复制构造器创建新的列表容器；本题元素是 Integer，这样复制就够了。

当前 Java 21 实现用 path.removeLast() 撤销末尾元素；也可用 path.remove(path.size() - 1) 按索引删除。两者都撤销刚加入的元素。

4. 先想，再展开核对

不要先看反馈。每题说出理由，而不只是猜结论。

path = [2] 时，下一位有哪些候选？

1 和 3。2 已经出现在当前路径中；1 的下标更小也不影响它成为候选。

从 [1,2,3] 保存并返回后，先恢复成哪条路径？

[1,2]，同时取消 3 的使用标记。再由上一层撤销 2，才恢复成 [1]。

如果只删除 path 末尾，不把 used[i] 改回 false，会怎样？

数字已经离开路径，却仍被认为在使用中，后面的分支会错误跳过它，导致漏解。

复习时先独立写出伪代码，再与 Leetcode46.java 中的 explore 实现核对。验收：三个官方样例得到完整排列，顺序不限；[1,2,3] 应有 6 个不同结果，每个结果包含三个数字且各用一次。现有 样例测试只打印，需要自行核对结果。

这种实现的时间复杂度是 O(n × n!)：有 n! 个结果，每个结果要复制 n 个元素；每个节点扫描 n 个候选也在这个量级内。辅助空间 O(n)，不计保存结果的 O(n × n!) 空间。这是对本课实现的计数推导。

复习速查：术语

路径 path：当前已做的选择。使用标记 used：当前路径占用了哪些下标。结果 res：完整路径的副本。回溯：递归探索后撤销选择，恢复状态。

四个检查点

  1. path.size() == nums.length 时，保存副本并返回。
  2. 每层遍历所有下标，跳过 used[i] 为 true 的候选。
  3. 选择时修改 path 和 used；递归结束后成对撤销。
  4. 撤销之后，状态应与本次选择之前完全相同。

全排列的数字互不相同；不需要排序，也不需要处理重复值去重。

Java 提醒

保存：new ArrayList<>(path)。撤销末尾：path.removeLast()（Java 21）。取消标记：used[i] = false。

时间 O(n × n!)，辅助空间 O(n)，结果空间 O(n × n!)。
