子集：每个数字，要还是不要？

学习目标：理解决策树的深度优先遍历，能独立解释状态变化，并凭记忆重写解法。

理解题意 · 手动枚举 · 递归状态 · 返回与撤销 · 自测 · 复习速查 · 补充：对比 46

1. 子集，就是从给定数字里挑一些

78 题目给出互不相同的数字，要求返回所有子集，不能重复。可以一个也不选，也可以全部选中。

输入 [1,2]，有四种结果：

结果含义
[]什么都不选
[1]只选 1
[2]只选 2
[1,2]两个都选

[2,1] 和 [1,2] 表示同一子集，不能各算一个答案。最终结果列表的排列顺序不限。

2. 怎么确保不漏？依次问每个数字

先问“1 要不要”，再问“2 要不要”。无论前面选了什么，当前数字都有两种决定。

开始：[]
├─ 不选 1：[]
│  ├─ 不选 2 → []
│  └─ 选   2 → [2]
└─ 选   1：[1]
   ├─ 不选 2 → [1]
   └─ 选   2 → [1,2]

这套解法本质上是深度优先遍历一棵二叉决策树：节点对应一次调用，两条边对应选或不选，叶子对应完整子集。

每条走到底的路都决定了所有数字的去留，所以得到一个完整子集。反过来，任何子集都有唯一的一串选与不选，因此这样既不会漏，也不会重复。

加上数字 3 后，每个已有子集又有“不加 3”和“加 3”两种情况：结果从 4 个变成 8 个。这是 Stanford 回溯课 Subsets 小节的决策树思路。

3. 递归需要记住哪两件事？

状态含义
path从根走到当前节点时，沿途已经选中的数字
process已完成的决策次数，也就是下一个要决定的数字下标

例如 nums=[1,2,3]，process=2、path=[1] 表示：前两个数字已经决定完，选了 1、没选 2；接下来决定 nums[2]，也就是 3。

process 从 0 开始，每次递归前进 1；path.size() ≤ process，因为不选也算完成一次决策。

一次递归的任务：前面的决定已经做好，请把从 process 开始的所有选法继续探索完。

不选：path 不变，下一层处理 process+1。选：先加入 nums[process]，下一层同样处理 process+1。

当 process == nums.length 时，没有数字需要决定，保存 path 的副本，然后返回。即使 path 为空，也要保存，因为空集同样是答案。

停一下：为什么不能用 path.size() 判断结束？

不选也会推进处理进度，却不会增加 path 的长度。结束表示“全部考虑完”，不是“全部选进来”。

4. 返回后，篮子为什么需要恢复？

仍看 process=2、path=[1]，接下来处理 3：

不选 3：下一层保存 [1]，返回后 path 仍为 [1]
选   3：加入 3 → 下一层保存 [1,3] → 返回 → 移除 3
本次调用结束：path 恢复为进入时的 [1]

path 是共享的列表。函数返回不会自动撤销列表修改，需要亲手把刚加入的元素移除。process 是 int，传入 process+1 不会改变当前调用自己的 process。

保存结果时，要复制当时的内容：new ArrayList<>(path)。如果只保存同一个列表引用，之后撤销选择，已保存的条目也会跟着变化。

按照“不选优先”的顺序，一层的工作可口头复述为：检查是否处理完 → 探索不选 → 加入当前数字 → 探索选 → 撤销加入。递归中的 return 只结束当前那次调用，回到调用处之后继续执行。因此完成“不选”的递归后，仍要继续执行“选”的分支；两条分支按先后顺序执行。

5. 先自己推，再展开核对

nums=[1,2,3]，process=1、path=[]。现在考虑哪个数字？如果不选，下一层的两个状态分别是什么？

查看反馈

考虑 nums[1]，也就是 2。不选后，process=2、path=[]；接下来考虑 3。没选数字不代表没有推进。

同样从 process=1、path=[] 出发，如果选了 2，递归处理后面的数字并返回，那么当前这一层需要撤销谁？

查看反馈

撤销自己加入的 2。更深层负责恢复自己的选择，因此返回到当前层时 path 应为 [2]，再移除 2，恢复进入时的 []。

不看上文，用自己的话说出：每层负责什么、什么时候收集、返回前恢复什么。明天再凭记忆复述一次。

复习速查：从思路到实现

初始：res 为空，path 为空，process = 0
每次调用：
  如果所有数字都决定完：保存 path 副本，返回
  不选当前数字：保持 path，递归处理下一个数字
  选当前数字：加入 nums[process]，递归处理下一个数字
  移除本层加入的数字，恢复 path

保存副本：new ArrayList<>(path)。撤销末尾：path.removeLast()（Java 21）。不提前添加空集，不需要 used，也不需要遍历所有候选的 for 循环。

先独立复述，再与 Leetcode78.java 核对。[1,2,3] 应产生 8 个不同子集，包含空集和全集；样例测试仅打印，需核对内容和重复情况。

本实现的计数推导：深度为 n，有 2ⁿ 个叶子；每个叶子复制路径，所有结果共保存 n·2ⁿ⁻¹ 个数字。因此时间 O(n·2ⁿ)，辅助空间 O(n)，结果空间 O(n·2ⁿ)。

下次复习，不看材料解释“为什么 path.size() 不等于 process”“返回后为什么还执行另一条分支”“为什么撤销、为什么复制”。任何不清楚的状态变化，都可以继续追问。
